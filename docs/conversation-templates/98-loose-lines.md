# Loose lines — everything else in `mca_dialogue`

> Every remaining pool in `assets/mca_dialogue/lang/` that no dialogue result names directly. Nothing in the corpus is left out of these templates; this is where the rest of it lives.

> Read [README.md](README.md) first.

## `dialogue.chatmode.`

Chat-mode plumbing: what a villager says when you speak to them in the chat box rather than through the menu — attention, being busy, asking you to clarify, not understanding. Spoken constantly, so these carry a lot of voice.


```text
POOL   dialogue key: dialogue.chatmode.attentive
WHO    see the group note above
       no shipped dialogue result names this pool directly
ARGS   %1$s = the player's name; check the current text for any %2$s+ it uses
SIZE   3 lines in this pool — the game picks one at random each time, so they must be interchangeable
```

```text
  dialogue.chatmode.attentive/1   [4 chars]
    en  Yes?
    >>  ............................................
    pt  Sim?
    >>  ............................................
```
